I started last month setting up a Linux server at home that I use for remote VS Code work. A lot of learning followed as I've never use Linux outside a server environment, except for some short periods of fiddling with Pop!_OS. I'll probably write up a longer article later, but for now the majority of my TILs the past month has been related to that project.

## Linux

- You can run simple GUI applications like `xeyes` and `git gui` over SSH using X11 and XQuartz
- [How to run VSCode remotely on a linux server with VS Code Remote/SSH extension](https://code.visualstudio.com/docs/remote/ssh)
- [You can setup default ports to forward on a remote VSCode workspace](https://share.getcloudapp.com/RBudYLl2)
- `  ̂ + ⎇ + T ` toggles the Terminal panel in VSCode
- [tmux integrates nicely with iterm2](https://iterm2.com/documentation-tmux-integration.html)
- Use `tmux select-layout even-vertical` to resize panes evenly
- `tmux -CC` starts in **C**ontrol mode (and disables e**C**ho)
- [How to fix iTerm 2 so it uses Natural Text Editing preset](https://apple.stackexchange.com/questions/154292/iterm-going-one-word-backwards-and-forwards/293988) (via @sobstel)
- neofetch - the CLI equivalent to "About my computer"
- [You can restrict which commands that can be run over SSH in `authorized_keys`](https://unix.stackexchange.com/questions/395776/how-to-remote-execute-ssh-command-a-sudo-command-without-password)
- [How to change hostname on ubuntu](https://linuxize.com/post/how-to-change-hostname-on-ubuntu-18-04/)

## Productivity/development

- ActiveRecord has a `comment` keyword argument for `add_column` that works with postgres
- [How to fix HMR in expo react-navigation](https://github.com/react-navigation/react-navigation/issues/6379#issuecomment-568012809)
- Assign env vars to constants and use `stub_const` over mocking env vars in tests
- `git checkout -` navigates back to your previously checked out branch similar to `cd -`
- @ in slack shows recent activity (via @jennysjogren)
- [Heroku supports multiple credentials for their Postgres databases](https://devcenter.heroku.com/articles/heroku-postgresql-credentials)
